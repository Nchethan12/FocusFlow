# FocusFlow — React Task Planner

A modern, responsive task management app built with **React** and **Vite**.

## Features

- ✨ **Task Management**: Add, complete, and delete tasks.
- 🏷️ **Categories & Priority**: Categorize by Work, Personal, or Study with Low, Medium, High priority badges.
- 🔍 **Real-time Search & Filter**: Filter by status (All, Active, Done) or search by keyword.
- 📊 **Progress Metrics**: Live dashboard stats showing total count, active count, completed count, and % progress bar.
- 💾 **Local Persistence**: Saves your tasks automatically to browser `localStorage`.
- ⚡ **Vite Powered**: Instant Hot Module Replacement (HMR) and fast build times.

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.

### 3. Build for Production
```bash
npm run build
```
